# WhatsApp Admin Dashboard Manual

The WhatsApp management panel is accessible in Olinethra Admin Dashboard at `/admin/whatsapp`.

---

## Capabilities

1. **Live Conversation Stream**: View all active WhatsApp chats with user display name, phone number, last activity, unread indicator, and status.
2. **Human Takeover / Pause AI**: Click **Pause AI / Take Over** to stop automated AI replies for a conversation.
3. **Resume AI**: Re-enable automated AI agent responses at any time.
4. **Direct Admin Reply**: Send direct human messages to the user's WhatsApp device from the dashboard interface.
5. **Project Brief & Lead View**: Inspect structured briefs generated during WhatsApp conversations.
6. **FAQ Insights & Analytics**: Monitor conversation metrics, lead conversion, human handoff counts, and inquiry topics.
